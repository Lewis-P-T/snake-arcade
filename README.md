# Snake Arcade

Browser Snake game — no dependencies, no build step. Open `index.html` or play live at https://lewis-p-t.github.io/snake-arcade/

Controls: arrow keys / WASD, P/Esc pause, Enter/Space start, H high scores (top 10 per speed + edge mode, saved in localStorage), D demo — a BFS autopilot that only eats when it can still reach its own tail. See `PROGRESS.md` for the build roadmap.
